【이 문서의 목적】

  이 문서는 SOXL 장기 분할매수 전략을 운영하는 누구든
  파라미터 수정 절차를 정확히 이해하고 실수 없이 실행할 수
  있도록 작성된 운영 매뉴얼입니다.

  전략 개요:
    - 종목    : SOXL (반도체 3배 레버리지 ETF)
    - 방식    : VIX 지수 + 시그마(변동성) 기반 분할매수
    - 목표    : 약 1년간 24회 진입 (월 평균 2회) 후 1년 홀딩
    - 운용 기간: ~2027년 5월 매수 완료 → 2028년 5월 청산 예정


----------------------------------------------------------------
【등장하는 파일 3가지와 역할】

  ┌─────────────────────────────────────────────────────────────┐
  │  파일명                       역할              직접 편집   │
  ├─────────────────────────────────────────────────────────────┤
  │  SOXL_VIX_SIGMA_BACKTEST.py  최적 배수 탐색 엔진  ✅ 여기만 │
  │  config.json                 설정값 저장소(자동)  ❌ 건드리지 말 것 │
  │  optimize_strategy.py        AI 월간 복기 엔진    필요 시만  │
  └─────────────────────────────────────────────────────────────┘

  ※ config.json은 백테스트와 AI 복기가 자동으로 갱신합니다.
     사람이 직접 편집하면 두 파일의 결과와 불일치가 생길 수 있습니다.


----------------------------------------------------------------
【전체 실행 흐름】

  매월 말 (권장: 마지막 주 금요일) 아래 순서로 실행합니다.

  ┌──────────────────────────────────────────────────────────┐
  │  STEP 1. 백테스트 실행                                   │
  │    → 4년 시장 데이터를 분석해 다음 달 최적 배수를 탐색   │
  │                                                          │
  │  STEP 2. config.json 자동 갱신                           │
  │    → 백테스트 결과를 "y"로 저장하면 자동 반영            │
  │                                                          │
  │  STEP 3. AI 월간 복기 실행                               │
  │    → 지난 한 달 매매 기록을 AI가 분석해 1개 변수 미세조정 │
  │                                                          │
  │  STEP 4. GitHub 자동 동기화                              │
  │    → AI 복기 결과를 "y"로 저장하면 GitHub에 자동 push    │
  └──────────────────────────────────────────────────────────┘

  도식:
    SOXL_VIX_SIGMA_BACKTEST.py
            ↓  "y" 입력
        config.json  (자동 갱신)
            ↓
    optimize_strategy.py
            ↓  "y" 입력
        config.json  (추가 미세조정) → GitHub 자동 동기화


----------------------------------------------------------------
【VS Code 터미널 실행 명령어】

  # STEP 1: 백테스트
  python SOXL_VIX_SIGMA_BACKTEST.py

  # STEP 3: AI 월간 복기
  python optimize_strategy.py


----------------------------------------------------------------
【왜 월 1회 백테스트가 필요한가?】

  당초 연초 1회 실행으로 설계되었으나, 아래 이유로 월 1회로 변경:

  1. 90일 롤링 시그마(변동성)는 매달 달라집니다.
     같은 배수라도 시장 변동성에 따라 실제 진입 가격이 매달 다르므로,
     한 달 전 최적값이 이번 달엔 최적이 아닐 수 있습니다.

  2. 실탄 소모 속도를 반영해야 합니다.
     AI 복기가 CURRENT_CASTS(누적 진입 횟수)를 보고 다음 달 타점을
     조정하는데, 그 조정값이 백테스트로 검증된 안전 범위 안에
     있는지 매달 확인하는 것이 안전합니다.

  3. 백테스트 → AI 복기가 하나의 월간 루틴으로 연결되어 있으므로
     두 작업의 실행 주기를 맞추는 것이 자연스럽습니다.

【수정이 필요한 상황별 작업 위치】

  상황                                    수정 파일
  ─────────────────────────────────────────────────────────────
  탐색 범위 변경 (MULT_NORMAL 등)         SOXL_VIX_SIGMA_BACKTEST.py
  수수료율 변경 (FEES)                    SOXL_VIX_SIGMA_BACKTEST.py
  홀딩 기간 변경 (HOLD_DAYS)             SOXL_VIX_SIGMA_BACKTEST.py
  매수 횟수 필터 변경 (170~240회)         SOXL_VIX_SIGMA_BACKTEST.py
  AI 프롬프트 수정                        optimize_strategy.py
  AI 분석 저장 로직 수정                  optimize_strategy.py
  Discord / Git 설정                     환경변수 또는 GitHub Secrets
  실제 운용 설정값 확인                   config.json (읽기 전용으로 참고)


----------------------------------------------------------------
【SAFETY_BOUNDS 설계 원칙】

  백테스트 파일(SOXL_VIX_SIGMA_BACKTEST.py) 안의 탐색 범위:

    MULT_NORMAL  : 0.65 ~ 0.85   평시 시장 (VIX 20 미만)
    MULT_FEAR    : 1.95 ~ 2.45   공포 시장 (VIX 20 이상)
    MULT_EXTREME : 2.50 ~ 2.75   극단 공포 (VIX 30 이상)

  설계 원칙:
    ① MULT_EXTREME 하한(2.50)은 반드시 MULT_FEAR 최대(2.45)보다
       커야 합니다. "극단 공포 배수 > 공포 배수" 논리를 보장합니다.

    ② config.json의 MULT_EXTREME 초기값(2.40)은 첫 백테스트 실행 후
       자동으로 2.50 이상으로 갱신됩니다. 직접 수정 불필요합니다.

    ③ 탐색 범위를 바꾸고 싶을 때는 반드시 백테스트 파일의
       SAFETY_BOUNDS 딕셔너리만 수정하세요.

【주의사항 요약】

  ✅ 파라미터 수정은 백테스트 파일(SOXL_VIX_SIGMA_BACKTEST.py)에서만
  ✅ 매월 말 백테스트 → AI 복기 순서로 실행
  ✅ 저장 여부는 결과를 충분히 확인한 후 "y" 입력
  ❌ config.json 직접 편집 금지
  ❌ API 키 / Webhook URL 코드에 직접 입력 금지
  ❌ 한 달에 2개 이상 변수 동시 수정 금지 (AI 복기 원칙)
