# 📈 VIX Sigma Position Manager

**VIX 기반 시그마 전략 + 30% 부분 익절 SOXL 운용 시스템**

VIX 공포 지수와 고정 시그마를 활용해 SOXL의 매수 타점을 계산하고, Discord로 실시간 알림을 제공하는 개인 운용 시스템입니다.  
**+30% 도달 시 보유 수량의 50% 부분 익절**을 핵심 규칙으로 삼아, 강세장에서 수익 실현과 추가 상승 여력을 동시에 추구합니다.

## ⚙️ 핵심 운용 원칙

- **종목**: SOXL (3배 레버리지 반도체 ETF)
- **매수 전략**: VIX 구간별 + 갭 하락 보정 + 고정 SIGMA 기반 LOC 매수
- **익절 규칙**: **+30% 도달 시 보유 수량의 50% 부분 익절** (나머지 50% 보유)
- **LONG / SHORT 이중 계좌**: LONG은 장기 적립, SHORT은 단기 타점 매도
- **파라미터 철학**: 과도한 최적화 자제. 연 1회 백테스트로 큰 틀만 검증
- **위험 관리**: SOXL의 높은 변동성을 인지하고, 전체 자산 중 감당 가능한 비중으로만 운용

## 🧮 매수 타점 계산 방식 (LONG)

**타점 = 기준가 × exp(-SIGMA × 조정배수)**

- 기준가: 장중 → 당일 시가 / 장전 → 전일 종가
- SIGMA: 고정값 (백테스트로 검증된 값, 기본 0.0460)
- 조정배수: VIX 구간 + 당일 갭 하락 폭에 따라 동적 보정

### VIX 구간별 기본 배수

| VIX 구간   | 배수  | 시장 국면   |
|------------|-------|-------------|
| 20 미만    | 1.40x | 평시        |
| 20 ~ 30    | 2.65x | 공포        |
| 30 이상    | 2.80x | 극단 공포   |

### 갭 하락 보정표

| 갭 하락 폭      | 적용 배수    |
|-----------------|--------------|
| -3% 이상        | 원배수 유지  |
| -3% ~ -5%       | 0.45         |
| -5% ~ -7%       | 0.25         |
| -7% ~ -10%      | 0.10         |
| -10% 초과       | 0.00         |

## 📅 운용 프로토콜

### 매일 루틴
- 정규장 개시 후 30분~1시간 내에 `sigma_position_manager.py` 실행 (또는 GitHub Actions 자동 실행)
- Discord로 **현재가**, **LOC 매수가**, **익절 지정가**, 부분 익절 알림 수신
- +30% 도달 시 **50% 매도** 실행 후 `ledger.json`에 기록

### 매수 체결 후 (중요)
1. `ledger.json` → `SOXL_LONG_BUY` 또는 `SOXL_SHORT_BUY`에 항목 추가
2. `git push` → GitHub Actions 자동 실행 → `config.json` 자동 갱신

### 매도 체결 후 (중요)
1. `ledger.json` → `SOXL_LONG_SELL` 또는 `SOXL_SHORT_SELL`에 항목 추가
2. `git push` → GitHub Actions 자동 실행 → `config.json` 자동 갱신

### ledger.json 기록 양식

```json
// 매수 시
{
    "date": "YYYY-MM-DD",
    "qty": 10,
    "price": 195.00,
    "total_amount": 1950.00,
    "casts": 5
}

// 매도 시
{
    "date": "YYYY-MM-DD",
    "qty": 5,
    "price": 220.00,
    "total_amount": 1100.00
}
```

### 정기 점검
- **연 1회 (1월 초)**: `SOXL_VIX_SIGMA_BACKTEST.py` 실행 후 전략 전반 검증
- **연 1회 (7월 초)**: `optimize_vix_multipliers.py` 실행 → VIX 배수 최적화 → `config.json` 자동 업데이트
- 상반기/하반기 각 1회, 연 2회 검증 사이클로 전략 안정성 유지
- 파라미터 대대적 변경은 최소화 (안정성 우선)

## 🔧 VIX 배수 최적화 (`optimize_vix_multipliers.py`)

연 1회 실행하여 최근 5년 데이터 기반으로 VIX 구간별 최적 배수와 SIGMA를 도출합니다.

```
python optimize_vix_multipliers.py
```

실행 후 업데이트 여부를 묻는 프롬프트가 표시됩니다:

```
config.json에 위 파라미터를 업데이트하시겠습니까? (y/n):
```

`y` 입력 시 `config.json`의 아래 항목이 자동 갱신됩니다:

| 항목          | 설명               |
|---------------|--------------------|
| `MULT_NORMAL` | VIX 20 미만 배수   |
| `MULT_FEAR`   | VIX 20~30 배수     |
| `MULT_EXTREME`| VIX 30 이상 배수   |
| `FIXED_SIGMA` | 고정 시그마 값     |
