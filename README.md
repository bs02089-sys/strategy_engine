# 📈 SOXL Sigma Position Manager

고정 시그마를 활용해 SOXL의 매수 타점을 계산하고 관리하는 개인 운용 시스템입니다. 복잡한 외부 지표와 매도 규칙을 제거하고, '통계적 저점 매수'라는 본질에 집중합니다.

---

## 🗂️ 프로젝트 파일 구성

| 파일명 | 역할 | 편집 정책 |
| :--- | :--- | :--- |
| `sigma_position_manager.py` | 실시간 관제 및 Discord 알림 엔진 | 수정 금지 |
| `SOXL_SIGMA_BACKTEST.py` | 연 2회 정기 시그마 검증 및 계산 | 연 2회 실행 |
| `config.json` | 시스템 설정 및 매매 파라미터 | 시스템 자동 업데이트 |
| `ledger.json` | 실전 체결 기록 장부 | 체결 시 수동 기록 |

---

## ⚙️ 핵심 운용 원칙

1. **매수 철학:** '1.5 시그마 하락'이라는 원칙을 고수합니다.
2. **잣대의 갱신:** 매년 1월/7월 총 2회, 지난 252 거래일 데이터를 분석하여 `FIXED_SIGMA` 값을 최신화합니다.
3. **단순 매매:** 익절 규칙 없이 오로지 저점 매수를 통해 SOXL의 상승분을 온전히 향유합니다.

---

## 🧮 매수 타점 계산 공식

**타점 = 전일 종가 × exp(-1.5 × FIXED_SIGMA)**

* 진입 배수: 1.5 (고정)
* 고정 시그마 (FIXED_SIGMA): 0.0818 (6개월마다 재산출)

---

## 📅 정기 운용 프로토콜

### 1. 매일 루틴
* 정규장 개시 전 `sigma_position_manager.py` 실행
* Discord 알림을 통해 당일 LOC 타점 확인 및 주문 실행

### 2. 반기 정기 점검 (1월/7월)
* `SOXL_SIGMA_BACKTEST.py`를 실행하여 최신 변동성을 측정합니다.
* 산출된 새로운 `FIXED_SIGMA` 값을 시스템이 `config.json`에 자동 반영하도록 합니다.

---

## 🔧 config.json 관리 정책

> ⚠️ 직접 수정 금지: 모든 파라미터 변경은 스크립트를 통해 이루어집니다.

| 항목 | 설명 | 갱신 주기 |
| :--- | :--- | :--- |
| `ENTRY_MULTIPLIER` | 매수 기준 배수 (1.5) | 고정 |
| `FIXED_SIGMA` | 시장 변동성 잣대 (0.0818) | 6개월 |
| `LAST_SIGMA_UPDATE` | 최근 갱신 날짜 | 6개월 |

---

## ⚠️ 주의사항
* 본 시스템은 SOXL의 장기 우상향을 전제로 수량을 늘려가는 적립식 전략입니다.
* 최종 매매 판단은 항상 본인이 합니다. 시스템은 대표님의 전략을 기계적으로 실행하는 도구일 뿐입니다.
