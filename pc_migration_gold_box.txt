[새 컴퓨터 이사용 보물상자 백업 가이드]

★ 나중에 PC를 새로 구입하거나 포맷할 때, 머리 아프게 처음부터 세팅할 필요 없이 
   이 텍스트 파일과 폴더 2개만 챙기면 10분 만에 완벽하게 복구됩니다! ★

----------------------------------------------------------------------
📦 챙겨야 할 보물상자 폴더 2개 (구 컴퓨터에서 USB로 복사)
----------------------------------------------------------------------

1. 첫 번째 보물상자: [내 주식 매매 엔진 폴더]
   - 목적: 수개월 동안 공들여 짠 파이썬 매매 코드와 소중한 주식 데이터(SOXL, TSLA 평단가 등)를 통째로 지키기 위함입니다.
   - 위치: 현재 작업 중이신 주식 프로젝트 폴더 전체 (예: strategy_engine 폴더)
   - 방법: 해당 폴더를 그대로 마우스 우클릭하여 복사 후 USB에 저장합니다.

2. 두 번째 보물상자: [진짜 컨티뉴 설정 폴더]
   - 목적: 오늘 밤 고생해서 세팅한 '제미나이 3.5 최신 뇌'와 '비밀 API 키' 설정을 그대로 가져가기 위함입니다.
   - 위치: C:\Users\bs020\.continue
   - 방법: 내 컴퓨터(내 PC)를 열고 주소창에 위 경로를 복사해 붙여넣은 뒤, 이동한 곳에 있는 [.continue] 폴더 전체를 그대로 USB에 저장합니다.

----------------------------------------------------------------------
🚀 새 컴퓨터에서 10분 만에 부활시키는 방법 (복구 순서)
----------------------------------------------------------------------

1단계: 프로그램 설치
   - 새 컴퓨터에 VS Code(Visual Studio Code)와 파이썬(Python)을 설치합니다.

2단계: 보물상자 던져넣기
   - USB에 담아온 [첫 번째 주식 폴더]를 새 컴퓨터의 원하는 위치에 놓습니다.
   - USB에 담아온 [두 번째 .continue 폴더]를 새 컴퓨터의 사용자 폴더 밑에 그대로 복사+붙여넣기 합니다.
     (경로 예시: C:\Users\새컴퓨터이름\.continue)

3단계: 플러그인 설치 끝!
   - VS Code를 켜고 왼쪽 블록 모양 아이콘(Extensions)을 눌러 [Continue]를 검색해 '설치(Install)' 버튼만 누릅니다.
   - 제미나이가 내 컴퓨터에 들어온 [.continue] 폴더 안의 config.json을 자동으로 읽어 들여, 추가 세팅 없이 즉시 '제미나이 3.5'로 작동하기 시작합니다!

----------------------------------------------------------------------
