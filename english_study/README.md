# AI 에이전트 영어 공부법 (여행 회화)

유튜브에 많이 소개된 "AI 영어 공부법"은 클로드·제미나이·챗GPT 같은 **챗봇과의 대화**가
전부다. 이 방법은 **코딩 에이전트**를 쓴다. 에이전트는 대화에 더해 **코드를 실행하고,
파일을 만들고, 네 실력을 기억하고 관리**할 수 있다. 여행지에서 불편 없이 대화할 수 있는
수준을 목표로 한다.

## 챗봇 공부법 vs 에이전트 공부법

| | 챗봇 공부법 | 에이전트 공부법 (이것) |
|---|---|---|
| 역할극 | 가능 | 가능 |
| 실수 교정 | 가능 | 가능 |
| 복습 계획 | 매번 새로 시켜야 함 | 파일에 저장, 자동 간격 반복 (Leitner) |
| 실력 기록 | 대화창에 휘발 | `progress.json`에 누적 |
| 나만의 표현장 | 없음 | `phrases.json`에 계속 추가 가능 |
| 오답 관리 | 기억에 의존 | 틀린 카드는 자동으로 더 자주 복습 |

핵심: **대화(역할극)는 에이전트와, 반복 학습은 스크립트가** 나눠 맡는다. 챗봇 공부법에서
"복습 좀 시켜줘" 하고 매번 다시 시키는 부분이 파일 기반으로 자동화된다.

## 시스템 구성

```
english_study/
├── README.md      # 이 매뉴얼
├── phrases.json   # 회화 표현 덱 — 상황별 표현 + 한국어 뜻 + 팁 (수정/추가 가능)
├── study.py       # 복습/퀴즈 CLI (표준 라이브러리만 사용, 설치 불필요)
└── progress.json  # 개인 복습 진척 — study.py가 자동 생성 (gitignore 대상)
```

## 하루 루틴 (30~60분)

핵심 흐름은 **표현을 먼저 배우고 → 역할극에서 써보고 → 퀴즈로 고정**하는 것이다.

1. **5분 — 복습** `python3 study.py review`
   지난날 배운 카드 중 오늘 복습할 것만 나온다. 맞으면 복습 간격이 1→3→7→14→30일로
   늘고, 틀리면 내일 다시 나온다 (Leitner 간격 반복).

2. **5~10분 — 표현 학습** `python3 study.py learn 호텔`
   오늘 할 상황의 표현을 영어 + 한국어 뜻 + 패턴 팁으로 **먼저 읽고 익힌다**.
   (진척 기록 없음 — 부담 없이 읽기만 하면 된다.)

3. **15~25분 — 역할극 (핵심)** 방금 익힌 표현을 실전에 써본다. 채팅에서 에이전트에게 말한다:

   > 호텔 체크인 역할극 해줘. 나는 방금 호텔 표현을 학습했어. 그 표현을 최대한 활용해서
   > 말할게. 영어로만 진행하고, 내가 틀리거나 어색하면 바로 고쳐줘.

   에이전트가 호텔 직원役을 맡고, 네 실수를 그 자리에서 교정한다. 익힌 표현이
   실제 대화에서 통하면 기억에 남고, 안 통하면 그게 진짜 복습 포인트가 된다.

4. **5분 — 확인 퀴즈** `python3 study.py quiz 호텔`
   역할극에서 써본 같은 표현을 퀴즈로 한 번 더 고정한다. 틀린 카드는 복습 큐에
   자동 등록되어 다음 날 다시 나온다.

5. **5분 — 정리** 역할극에서 새로 배운 표현을 에이전트에게 말한다:

   > 오늘 배운 "I'd like a room with a view."를 phrases.json에 추가해줘.

   덱이 계속 커지면서 내 상황에 맞는 표현장이 된다.

## 역할극 규칙

- **역할극 전에 `study.py learn <상황>` 으로 그 상황의 표현을 먼저 익힌다** —
  그래야 역할극이 "맨땅에 헤딩"이 아니라 "배운 것의 실전 활용"이 된다.
- 에이전트가 상대役(호텔 직원/택시 기사/점원), 너는 영어로만.
- 모르는 표현은 한국어로 말해도 된다 — 에이전트가 영어 표현을 알려주고 이어서 진행.
- 같은 상황을 일주일에 한 번 반복해서, 부드럽게 나올 때까지.
- 발음이 궁금하면: "이 문장 발음 기호로 써줘" 또는 "이 문장을 천천히 읽어줘"라고 요청.

## 상황별 진행 순서 (추천)

1. 공항 · 입국심사
2. 호텔
3. 식당
4. 카페 · 테이크아웃
5. 교통 (택시 · 버스)
6. 길 찾기
7. 쇼핑 · 환불
8. 응급 · 도움
9. 스몰토크

## CLI 명령어

```bash
cd english_study

python3 study.py learn 호텔          # 표현 학습 (영어 + 뜻 + 팁) — 역할극 전에 먼저
python3 study.py review              # 오늘 복습할 카드 (간격 반복)
python3 study.py review 호텔         # 특정 상황만 복습
python3 study.py quiz                # 전체 퀴즈 (한국어 → 영어)
python3 study.py quiz cafe           # 카페 상황만 퀴즈
python3 study.py list                # 전체 표현 목록
python3 study.py list 호텔           # 호텔 표현 목록
python3 study.py stats               # 진척 통계 (학습/숙달/복습 대기/오답)
```

- 상황 지정은 영어 id(`airport`, `hotel`, ...) 또는 한국어 제목(`공항 · 입국심사`) 모두 가능.
- 정답 판정은 키워드 매칭이라 "자연스럽게 바꿔 말한" 표현은 틀림 처리될 수 있다 —
  그건 스크립트의 한계가 아니라 설계다. 자연스러운 대안 표현 교정은 채팅 역할극에서 받는다.

## 팁

- 복습은 매일 5분이면 충분하다. 간격 반복이라 며칠 미루면 카드가 쌓인다.
- 문장을 통째로 외우려 하지 말고 **패턴**(tip에 적힌 것)을 익혀라. 단어만 바꿔도 통한다.
- 2주에 한 번: "여행 시나리오 하나 만들어서 내가 말해볼게, 피드백 줘"라고 요청해 종합 점검.
- 티켓팅·주문처럼 숫자가 들어가는 표현은 역할극에서 숫자 바꿔 연습하면 실전에 강하다.

## 역할극 시작 프롬프트 모음

`study.py learn <상황>` 으로 표현을 익힌 뒤, 그 상황에 맞는 프롬프트를 쓰면 된다:

```
호텔 체크인 역할극 해줘. 나는 방금 호텔 표현을 학습했어. 그 표현을 최대한 활용해서
말할게. 영어로만 진행하고, 내가 틀리거나 어색하면 바로 고쳐줘.

식당에서 저녁 식사 주문하는 역할극 해줘. 나는 방금 식당 표현을 학습했어.
배운 표현 위주로 말할게. 영어로만 진행하고, 내가 틀리면 바로 고쳐줘.

공항에서 입국심사 받는 역할극 해줘. 나는 방금 공항 표현을 학습했어.
심사관 질문에 그 표현들로 대답하는 연습이야. 한국어 힌트 없이 진행해줘.
```
