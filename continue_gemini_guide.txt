💡 실전 사용법 1: 내 코드에 대해 대화하기 (단축키: Ctrl + L)
----------------------------------------------------------------------
내 주식 코드의 특정 부분을 인공지능에게 물어보고 분석할 때 사용하는 방법입니다.

1. 질문하기:
   - 파이썬 코드 중에서 궁금하거나 분석하고 싶은 영역을 마우스로 쭉 드래그(블록 지정)합니다.
2. 단축키 실행:
   - 그 상태에서 키보드의 [Ctrl + L]을 누릅니다.
3. 확인 및 대화:
   - 화면 왼쪽(또는 오른쪽)에 사이드바 대화창이 열리면서, 선택한 코드가 자동으로 대화방에 들어갑니다.
   - 아래 입력창에 한글로 자유롭게 질문을 던집니다.
   
   ※ 활용 예시:
   - "이 구간에서 에러가 나는데 원인이 뭘까?"
   - "SOXL, TSLA 매매 로직을 조금 더 효율적으로 고쳐줘."

----------------------------------------------------------------------
💡 실전 사용법 2: 코드 창에서 바로 수정·생성하기 (단축키: Ctrl + I)
----------------------------------------------------------------------
인공지능이 내 코드 창에 직접 들어와 코드를 고치거나 새로 짜게 만드는 강력한 방법입니다.

1. 위치 잡기:
   - 수정을 원하는 코드 줄을 마우스로 드래그하거나, 새 코드를 짜고 싶은 빈 공간에 마우스 커서를 찍어둡니다.
2. 단축키 실행:
   - 키보드의 [Ctrl + I]을 누릅니다.
3. 명령 입력:
   - 코드 창 한가운데에 작은 명령 입력창이 뜨면, 원하는 지시 사항을 한글로 치고 [Enter]를 누릅니다.

4. 최종 선택 (가장 중요 ⭐):
   - 마음에 들면: [Ctrl + Enter] 를 눌러 내 코드에 적용(수락)합니다.
   - 마음에 안 들면: [Ctrl + Shift + Backspace] 를 눌러 취소(거절)합니다.

----------------------------------------------------------------------
💡 실전 사용법 3: 흐릿한 유령 글씨 자동 완성 (단축키: Tab)
----------------------------------------------------------------------
코드를 타이핑하다 보면 제미나이가 내 의도를 파악하고 다음에 올 코드를 흐릿한 회색 유령 글씨로 미리 보여줍니다. 마음에 들면 [Tab] 키를 누르면 자동 완성됩니다.

----------------------------------------------------------------------
💡 실전 사용법 4: 다른 파일 열고 대화 및 파일 전체 먹이기 (@ 기능)
----------------------------------------------------------------------
현재 작업 중인 파일뿐만 아니라, 내 폴더에 있는 다른 파일들을 열어놓고도 제미나이와 자유롭게 대화할 수 있는 강력한 기능입니다.

1. 다른 파일 열고 바로 질문하기 (Ctrl + L):
   - 궁금한 다른 코드 파일을 화면에 띄우고 마우스로 드래그한 뒤 [Ctrl + L]을 누릅니다.

2. 파일 전체를 제미나이에게 한 방에 던져주기 (@ 기능):
   - [Ctrl + L]을 눌러 왼쪽 대화창을 켭니다.
   - 질문 입력창에 골뱅이 기호[@]를 타이핑합니다.
   - 리스트에서 파일(예: optimize_strategy.py)을 선택하고 한글로 질문을 던집니다.

   ※ 활용 예시:
   - "@optimize_strategy.py 이 파일 전체 구조 좀 설명해 줘."
