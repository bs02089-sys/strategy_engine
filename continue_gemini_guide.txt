💡 실전 사용법 1: 내 코드에 대해 대화하기 (단축키: Ctrl + L)
----------------------------------------------------------------------
내 주식 코드의 특정 부분을 인공지능에게 물어보고 분석할 때 사용하는 방법입니다.

1. 질문하기:
   - 파이썬 코드 중에서 궁금하거나 분석하고 싶은 영역을 마우스로 쭉 드래그(블록 지정)합니다.
2. 단축키 실행:
   - 그 상태에서 키보드의 [Ctrl + L]을 누릅니다.
3. 확인 및 대화:
   - 화면 왼쪽(또는 오른쪽)에 사이드바 대화창이 열리면서, 선택한 코드가 자동으로 대화방에 들어갑니다.
   - 아래 입력창에 한글로 자유롭게 질문을 던집니다.
   
   ※ 활용 예시:
   - "이 구간에서 에러가 나는데 원인이 뭘까?"
   - "SOXL, TSLA 매매 로직을 조금 더 효율적으로 고쳐줘."
   - "이 코드의 주석을 상세하게 달아줘."

----------------------------------------------------------------------
💡 실전 사용법 2: 코드 창에서 바로 수정·생성하기 (단축키: Ctrl + I)
----------------------------------------------------------------------
인공지능이 내 코드 창에 직접 들어와 코드를 고치거나 새로 짜게 만드는 강력한 방법입니다.

1. 위치 잡기:
   - 수정을 원하는 코드 줄을 마우스로 드래그하거나, 새 코드를 짜고 싶은 빈 공간(여백)에 마우스 커서를 찍어둡니다.
2. 단축키 실행:
   - 키보드의 [Ctrl + I]를 누릅니다.
3. 명령 입력:
   - 코드 창 한가운데에 작은 명령 입력창이 뜨면, 원하는 지시 사항을 한글로 치고 [Enter]를 누릅니다.
   
   ※ 활용 예시:
   - "이 함수에 디스코드 웹훅 알림을 보내는 코드 추가해 줘"
   - "VIX_CONFIG 조건문 아래에 예외 처리 로직 짜줘"

4. 최종 선택 (가장 중요 ⭐):
   - 제미나이가 실시간으로 코드를 작성하며 파란색(추가) / 빨간색(삭제)으로 수정본을 보여줍니다.
   - 마음에 들면: [Ctrl + Enter] 를 눌러 내 코드에 적용(수락)합니다.
   - 마음에 안 들면: [Ctrl + Shift + Backspace] 를 눌러 취소(거절)합니다.

----------------------------------------------------------------------
💡 실전 사용법 3: 흐릿한 유령 글씨 자동 완성 (단축키: Tab)
----------------------------------------------------------------------
배관 공사가 완벽하게 끝났기 때문에, 이제 코드를 타이핑하다 보면 제미나이가 내 의도를 파악하고 다음에 올 코드를 흐릿한 회색 유령 글씨로 미리 보여줍니다.

1. 적용하기:
   - 제미나이가 미리 보여주는 회색 코드가 내 마음에 쏙 든다면, 키보드의 [Tab] 키를 탁 누릅니다.
2. 결과:
   - 귀찮게 타이핑할 필요 없이 코드가 한 방에 자동으로 완성됩니다.
